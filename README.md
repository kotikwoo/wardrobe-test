# wardrobe-test

A temporary page that tests background removal on a device. Photos are processed on
the device and are not uploaded.

Third-party parts:

- ISNet general model: https://github.com/xuebinqin/DIS (Apache-2.0), ONNX export from
  https://github.com/danielgatis/rembg (MIT). Modified: converted to 16-bit weights.
- Transformers.js (Apache-2.0), ONNX Runtime Web (MIT), React (MIT).
